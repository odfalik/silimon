Silimon

Apple Silicon performance metrics in your menu bar.
No sudo required.

macOS 13+ Apple Silicon MIT License 
# Install with Homebrew
brew tap odfalik/silimon
brew install silimon

# Launch
silimon

⚡ Real-time Power

Monitor CPU, GPU, and Neural Engine power consumption in watts. See exactly how much power your Mac is using.

🎯 CPU Clusters

Track E-core and P-core usage and frequencies separately. Understand when your Mac shifts between efficiency and performance.

🎮 GPU Metrics

See GPU utilization percentage and frequency. Know when graphics-intensive tasks are running.

💾 Memory Pressure

Monitor RAM usage, memory pressure state, and swap. Get warned before your Mac starts slowing down.

🔋 Battery Status

Battery level, charging state, and time remaining. Never be surprised by a dead battery.

📊 History Charts

60-second sparkline charts show trends at a glance. Export data to CSV or JSON for analysis.
